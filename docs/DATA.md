# 数据来源与边界

当前包含香港与英国 20 个授课型硕士项目的 Beta 候选资料。数据位于 `backend/data/alpha_v1/`，每个项目的数据包包含官网来源、适用学年、核验日期、版本、字段状态与哈希。

- 当年的官网门槛用于相应学年的正式判断。
- 旧学年资料只作为明确标注的历史参考；不会替代当年的要求。
- 缺失、模糊或待核实的门槛保持不确定状态，不用 AI 猜测。
- 仓库不是院校官方渠道，也不代表与所列大学存在合作或背书。
- 公开 Demo 固定在 2026-09-07 快照；资料可能更新，申请时以学校官方页面为准。

测试和演示申请档案均为合成资料。数据更新贡献应附官方页面 URL、适用年份、核验日期和修改原因；不要提交真实申请人的成绩单、联系方式或申请材料。

代码许可证不赋予第三方官网文字、排名资料、机构名称或标识的版权，详见 `NOTICE`。
